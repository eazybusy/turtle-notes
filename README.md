# შენი ლეგენდარული გამონათქვამები 🐢

ერთგვერდიანი სახალისო საიტი — შეყვარებულს შეუძლია თავისი იუმორისტული
გამონათქვამები ჩაწეროს და ბარათებად შეინახოს. ჩანაწერები **საერთოა ყველა
მოწყობილობაზე** (ბექენდი: Upstash Redis). თუ ბექენდი ჯერ არ დაყენებულა ან
offline ხარ, საიტი ავტომატურად ლოკალურ რეჟიმზე გადადის.

## ფაილები
```
turtle-notes/
├── index.html          ← მთავარი გვერდი
├── style.css           ← დიზაინი (ოკეანის თემა)
├── script.js           ← ლოგიკა (API + ლოკალური რეზერვი)
├── assets/             ← სურათი + აპლიკაციის ხატულები
├── api/notes.js        ← სერვერული ფუნქცია (GET/POST/DELETE)
├── package.json        ← @upstash/redis
├── .env.example        ← საჭირო environment variables
└── .gitignore
```

## 1. ატვირთვა Vercel-ზე (GitHub-ით, რეკომენდებული)
რადგან ბექენდი და დამოკიდებულებები გვაქვს, ყველაზე მარტივია Git-ით:
1. ატვირთე ეს ფოლდერი GitHub-ის რეპოზიტორიად.
2. [vercel.com/new](https://vercel.com/new) → **Import** ეს რეპო.
3. **Project Name** ჩაწერე: `iumorinanikiturad`
   → საიტის მისამართი გახდება **iumorinanikiturad.vercel.app**
   (თუ ეს სახელი დაკავებულია, Vercel სუფიქსს დაამატებს; სხვა სახელი აირჩიე
   ან მოგვიანებით Settings → Domains-ში დაამატე სასურველი დომენი.)
4. **Deploy**. ამ ეტაპზე საიტი უკვე მუშაობს — ჯერ ლოკალურ რეჟიმში.

> ალტერნატივა CLI-ით: `npm i -g vercel` → ფოლდერში `vercel` → `vercel --prod`.

## 2. ბექენდის ჩართვა (Upstash Redis — უფასო)
რომ ჩანაწერები საერთო გახდეს ყველა მოწყობილობაზე:
1. Vercel-ში → შენი პროექტი → **Storage** ტაბი → **Create Database**.
2. Marketplace-იდან აირჩიე **Upstash** → **Redis**.
3. რეგიონად აირჩიე ევროპა (მაგ. Frankfurt / `eu-west-1`) — საქართველოსთან ახლოსაა.
4. **Connect** შენს პროექტთან. Upstash ავტომატურად ამატებს ცვლადებს:
   `UPSTASH_REDIS_REST_URL` და `UPSTASH_REDIS_REST_TOKEN`.
5. **Redeploy** (Deployments → ⋯ → Redeploy). მას შემდეგ საიტი „ღრუბლის"
   რეჟიმზეა — ფუტერში წერია: *„ჩანაწერები საერთოა ყველა მოწყობილობაზე ☁️"*.

Upstash-ის უფასო ლიმიტი: 500K ბრძანება/თვეში — ამ საიტს ბოლომდე ჰყოფნის.

## 3. ლოკალურად გაშვება
```bash
npm i -g vercel
cd turtle-notes
vercel link          # დააკავშირე პროექტთან
vercel env pull .env.local   # ჩამოწერე Upstash-ის ცვლადები
vercel dev           # http://localhost:3000 (API-თ ერთად)
```
უბრალო preview (API-ს გარეშე, ლოკალური რეჟიმი): `index.html` ბრაუზერში გახსენი.

## პერსონალიზაცია
- **ტექსტები** — `index.html` (სათაური, ქვესათაური).
- **ფერები** — `style.css` → `:root`.
- **წინასწარ შევსება** (მხოლოდ ლოკალურ რეჟიმში) — `script.js` → `SEED_NOTES`.

## API
| მეთოდი | მისამართი           | აღწერა                    |
|--------|---------------------|---------------------------|
| GET    | `/api/notes`        | ყველა ჩანაწერი            |
| POST   | `/api/notes`        | დამატება — body `{ text }`|
| DELETE | `/api/notes?id=..`  | წაშლა id-ით               |

დამატება და წაშლა. პირადი, „ჩვენს შორის" საიტისთვის ეს ჩვეულებრივ საკმარისია
(ბმული უბრალოდ არ გაასაჯაროო). თუ დაცვა დაგჭირდა (მაგ. საერთო პაროლი) — მითხარი.
